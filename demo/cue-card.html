Opening · 0:00-1:00 (verbatim)

"Public data warehouses lag Solana by minutes, and they flatten program semantics down to token transfers. In 2026 Kamino cut its liquidation penalty by ninety percent, and there is no public dataset that can measure what that did to liquidators. So I built one."

Architecture · 1:00-2:30 (3 decisions)

1. Raw bytes first. Decode is replayable; a wrong offset is a fixable bug, not lost data.
2. Key (pubkey, slot, write_version). ~36% of writes rewrite one account per slot. write_version keeps every intra-slot version.
3. Data batch, then checkpoint. Prefer duplicates over holes.

War story · 5:00-6:00

accounts_data_slice sized for Reserve (8,624 B). Obligations are 3,344 B, so every Obligation arrived empty from slot 437,903,892.
158 hours of garbage, every monitor green. Throughput was never the problem, so no liveness signal saw it.
Found by data-distribution audit: one kind's max slot froze while others advanced.
Fix: payload-shape guard, a funded account with a zero-length payload is a shape the chain does not produce.
Fixed facts: 64,650 rows lost · 158.91h · 4,385 accounts (3,175 obligations). "Throughput is not integrity."
Money: RPC $1-2/mo · 7.45 KB/s. "The cost problem was ClickHouse, not the stream."
